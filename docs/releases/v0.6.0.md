Sound. Milestone 3 of 7.

**New**
- Clips now have sound, as AAC 48 kHz stereo at 160 kbps per track.
- **Fullscreen apps and games only** mode: two separate tracks, **Game** (the game's own sound) and **System** (everything else, such as voice chat or music).
- **Whole screen** mode: one **System** track with everything.
- **Record my microphone too** switch: adds a separate **Microphone** track. Off by default.
- Tracks are lined up with the video using the capture clock, so sound stays in step with the picture.

**Good to know**
- Most players play only the first sound track (Game) unless you pick another one. In VLC use Audio > Audio Track.
- Needs Windows 10 version 2004 or newer for the separate Game track; older versions fall back to a single System track.

**Installing**
Exit Papyrus first (right-click its tray icon, Exit Papyrus). Download `Papyrus-Setup-0.6.0.exe` below and run it. The installer is not code-signed, so Windows SmartScreen will show "Windows protected your PC": click **More info**, then **Run anyway**.
