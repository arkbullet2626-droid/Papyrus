One sound track per app.

**Changed**
- Clips now record sound from these sources only, each on its own track:
  - **Game**: the fullscreen game (fullscreen-only mode)
  - **Spotify**
  - **Discord**
  - **Microphone**, if you switch it on
- Nothing else is recorded. Browsers, notification sounds, other apps and Papyrus's own start, stop and save beeps are never in a clip.
- Spotify and Discord are picked up within a few seconds of starting and dropped when they close, without restarting the buffer.
- The "System" track is gone.

**Fixed**
- The memory estimate line in the window was cut off.

**Good to know**
- Most players play only the first sound track (Game) unless you pick another one. In VLC use Audio > Audio Track.
- In Whole screen mode there is no game track, so a clip has Spotify and Discord sound only.

**Installing**
Exit Papyrus first (right-click its tray icon, Exit Papyrus). Download `Papyrus-Setup-0.7.0.exe` below and run it. The installer is not code-signed, so Windows SmartScreen will show "Windows protected your PC": click **More info**, then **Run anyway**.
