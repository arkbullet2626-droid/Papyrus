Papyrus Studio: watch and edit your clips.

**New: Papyrus Studio**
Open it with the **Clips and editor** button in the Papyrus window, from the tray menu, or from the Start menu.
- **Clip list** with every clip in `Videos\Papyrus`, newest first.
- **Player** to watch a clip.
- **Sound tracks** shown one per row (Game, Spotify, Discord, Microphone). **Listen** picks which one you hear.
- **Clip length:** move Start and End, or set them from the current playback position, and play just the selected part.
- **Per track:** untick **Keep** to leave a track out, give each track its own start and end, and change its volume from 0 to 200%.
- **Save as a new clip:** the original is never changed. The picture is copied without re-encoding, so saving is fast and loses no quality. Only a track whose volume you changed is re-encoded.
- **Delete** moves a clip to the Recycle Bin.

**Good to know**
- The clip's Start moves in 1-second steps; the End can be anywhere.
- The installer is larger now (about 60 MB) because Studio brings its own runtime. The recorder itself is unchanged in size.

**Fixed**
- The help text at the bottom of the Papyrus window was cut off.

**Installing**
Exit Papyrus first (right-click its tray icon, Exit Papyrus). Download `Papyrus-Setup-0.8.0.exe` below and run it. The installer is not code-signed, so Windows SmartScreen will show "Windows protected your PC": click **More info**, then **Run anyway**.
