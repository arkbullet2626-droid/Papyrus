Hotkey uses exactly what you press.

**Fixed**
- Setting the save hotkey to a single key such as F8 now gives F8, not Ctrl + Shift + F8. Whatever key or combination you press is what is used.

**Good to know**
- A single ordinary key (a letter or number) as the hotkey will stop that key typing in other apps while the replay buffer is on. Function keys such as F8 are a safer choice.

**Installing**
Exit Papyrus first (right-click its tray icon, Exit Papyrus). Download `Papyrus-Setup-0.9.6.exe` below and run it. The installer is not code-signed, so Windows SmartScreen will show "Windows protected your PC": click **More info**, then **Run anyway**.
