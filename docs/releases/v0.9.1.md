Editor timeline with drag bars and waveforms.

**New in the editor**
- **Drag bars:** the clip has a timeline strip with a bar on each side. Drag them to cut the start and end. The part that will be removed is dimmed.
- **A strip per sound track** with the same two bars, so each track can be shortened on its own.
- **Waveforms:** each sound track's strip shows how loud it is over time, so you can see where the sound is.
- **Playback line** moves across every strip while the clip plays. Click anywhere on a strip to jump there.
- **Reset** puts all the bars back to the full clip.
- A track with Keep unticked is shown faded.

**Fixed**
- Hovering a clip no longer pops up a "Click to open in the editor" tip.

**Installing**
Exit Papyrus first (right-click its tray icon, Exit Papyrus). Download `Papyrus-Setup-0.9.1.exe` below and run it. The installer is not code-signed, so Windows SmartScreen will show "Windows protected your PC": click **More info**, then **Run anyway**.
