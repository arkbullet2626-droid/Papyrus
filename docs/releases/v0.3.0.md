Control window and tray icon. Milestone 2 of 7, with part of Milestone 4 brought forward.

**New**
- Papyrus now opens a small window instead of a black console. The replay buffer is **off** until you switch it on.
- One big button turns the replay buffer on or off. When it is off, nothing is captured or encoded and the recorder's memory is released.
- **Always on** switch: starts Papyrus with Windows, in the tray, with the replay buffer already on.
- Tray icon near the clock (red dot = buffer on, grey = off). Left-click opens the window; right-click has the same switches plus Exit.
- **Save clip now** button, in addition to the Ctrl+Shift+F9 hotkey.

**Installing**
Close any older Papyrus window first. Download `Papyrus-Setup-0.3.0.exe` below and run it. The installer is not code-signed, so Windows SmartScreen will show "Windows protected your PC": click **More info**, then **Run anyway**.
