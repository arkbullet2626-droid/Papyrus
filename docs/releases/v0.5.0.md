**New**
- **Record** setting with two choices:
  - **Fullscreen apps and games only** (the default): while the replay buffer is on, Papyrus records only when a fullscreen app or game is in front on the main monitor. On the desktop it records nothing.
  - **Whole screen (desktop too)**: records the main monitor all the time, as before.
- In fullscreen-only mode the buffer pauses when you switch away from the game and continues when you come back, so what was already recorded is kept. If no fullscreen app comes back within 5 minutes the recorder shuts down and frees its memory until the next one.
- The tray dot is red while recording, amber while switched on but waiting or paused, and grey when off.

**Installing**
Exit Papyrus first (right-click its tray icon, Exit Papyrus). Download `Papyrus-Setup-0.5.0.exe` below and run it. The installer is not code-signed, so Windows SmartScreen will show "Windows protected your PC": click **More info**, then **Run anyway**.
